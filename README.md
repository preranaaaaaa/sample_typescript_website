# AWT Assignment 1 – TypeScript

## Subject

Advanced Web Technologies (24MCA301)

## Description

This assignment demonstrates the basic concepts of TypeScript through a store inventory system.

## Topics Covered

* Basic Types and Variables
* Functions and Type Safety
* Default Parameters
* Array Methods using map()
* Block Scope and Function Scope
* Interfaces and Objects
* Interface Inheritance
* TypeScript Compilation and Debugging

## How to Run

Install dependencies:

```bash
npm install
```

Compile TypeScript:

```bash
npx tsc
```

Run the JavaScript output:

```bash
node dist/inventory.js
```

## Error Demonstration

The file `inventory-error-demo.ts` contains two intentional TypeScript errors to demonstrate type checking and compiler error messages.
